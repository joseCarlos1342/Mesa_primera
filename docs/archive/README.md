# Archivo Historico

Esta carpeta contiene documentacion historica, auditorias antiguas y bitacoras cerradas.

Reglas:

- No usar estos archivos como fuente de verdad operativa sin verificar fecha y contexto.
- Toda guia viva debe permanecer fuera de `docs/archive/`.
- Cuando un documento deje de describir el estado actual del codigo, debe moverse aqui o reescribirse.

Subcarpetas:

- `sprints/`: bitacora historica por sprint.
- `audits/`: auditorias, analisis y planes ya ejecutados o superados por el codigo actual.
