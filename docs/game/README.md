# Juego

Documentacion viva del motor autoritativo de Mesa Primera.

Archivos vivos:

- `phases.md`: fases reales registradas actualmente por el motor.
- `GAME_SCENARIOS.md`: escenarios funcionales y expectativas del motor.
- `MESA_VERSIONS.md`: historial de cambios del motor y fixes validados.

Documentacion historica movida a `docs/archive/audits/`:

- auditorias de logica ya resueltas o superadas por el codigo.
- planes de correccion ya ejecutados o parciales.
- notas de refactor y fixes historicos que ya no describen el estado operativo actual.
- planes maestros o propuestas de arquitectura que ya no son fuente de verdad del runtime actual.
